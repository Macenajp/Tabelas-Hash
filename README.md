# Tabelas Hash | Trabalho Prático
Projeto de processamento e indexação de uma base com cerca 3 milhões de avaliações de livros da Amazon (2,7 GB) usando estruturas de dados em Java.

<br>

## 📌| Sobre o trabalho:
Este trabalho foca na implementação de uma Tabela Hash com capacidade fixa (1.000.003 posições) com tratamento de colisões por encadeamento separado. O objetivo é mapear usuários para seus livros melhor avaliados e gerar estatísticas comparativas entre três funções hash diferentes: FNV1a, Polinomial (base 31) e djb2.

**Restrições:**
- Somente os tipos `int`, `float`, `double`, `char` e `String`, além de vetores desses tipos. Classes empacotadoras (`Integer`, `Double`, `Float`, `Character` etc.) não são permitidas.
- Nenhum método pronto, exceto leitura e escrita de arquivos e o contador de tempo (`System.nanoTime`).
- Código inteiramente em português: classes, métodos, variáveis e comentários
